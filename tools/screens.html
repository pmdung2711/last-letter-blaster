LAST LETTER BLASTER · SCREENS

Game screens, desktop and mobile

The desktop screens use the GDD canvas (480×270 drawn at 2×). On mobile, the run and pause screens keep the landscape canvas above the keyboard. The mobile menus assume a portrait canvas (270×480), which the GDD does not define yet. All text is bold system monospace.
